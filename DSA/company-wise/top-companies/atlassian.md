## 🏢 Interview Format & Engineering Expectations

- **Interview Rounds:** 1 OA + 1 Screen + 4 Onsite rounds (Data Structures, System Design, Code Design / Pairing, Values)
- **High-Frequency Topics:** `Hash Maps, Heaps, String Processing, Design (Rate Limiter, Voting System, Tagging)`
- **Company Context & Strategy:** Atlassian tests interactive pair-programming. Writing testable, cleanly refactored code with good design patterns matters just as much as algorithmic complexity.

## 💡 How to Prepare for Atlassian

1. **Master the Top 20 First:** Over 50% of phone screen questions at Atlassian come directly from the top 20 frequency list above.
2. **Time Yourself:** Strict 20-minute timer per medium question. Practice articulating your thought process before writing code.
3. **Handle Edge Cases Early:** Before writing logic, state: *"The edge cases I want to test are: empty array, all negative, duplicates, and large values."*
4. **Tie Code to Architecture:** Always state the space-time tradeoff and discuss how this scales when data exceeds single-machine memory.
