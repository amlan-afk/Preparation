## 🏢 Interview Format & Engineering Expectations

- **Interview Rounds:** 1 Technical Screen + 3-4 Onsite rounds (2-3 Coding rounds, 1 Engineering Manager / HR)
- **High-Frequency Topics:** `Hash Maps, Linked Lists, Stacks, Queues, Graphs, Design (LRU Cache, Stock Span, Leaderboard)`
- **Company Context & Strategy:** Bloomberg loves custom data structure design (combining Maps + Lists/Heaps), financial simulation problems, string parsing, and multithreading basics for senior candidates.

## 💡 How to Prepare for Bloomberg

1. **Master the Top 20 First:** Over 50% of phone screen questions at Bloomberg come directly from the top 20 frequency list above.
2. **Time Yourself:** Strict 20-minute timer per medium question. Practice articulating your thought process before writing code.
3. **Handle Edge Cases Early:** Before writing logic, state: *"The edge cases I want to test are: empty array, all negative, duplicates, and large values."*
4. **Tie Code to Architecture:** Always state the space-time tradeoff and discuss how this scales when data exceeds single-machine memory.
