# 10-week SDE 2 preparation roadmap

This sequence adapts the supplied guide. DSA and speaking practice continue throughout. Shift weeks as needed; mastery is measured by being able to explain and apply the material, not by checking boxes.

| Week | Main focus | Concrete outputs |
|---|---|---|
| 1 | Resume mastery + project deep dive | Resume bullets mapped; UMR architecture note; 2 polished project stories |
| 2 | Core Java | Collections, equality/hash, exceptions, generics, streams; explain HashMap clearly |
| 3 | Advanced Java + Spring fundamentals | JVM, concurrency basics, request lifecycle, DI, configuration |
| 4 | Spring Boot + REST + GraphQL | Validation, DTOs, errors, tests, downstream failures; crisp architecture explanation |
| 5 | React + TypeScript | rendering, hooks, state choices, performance, app structure |
| 6 | System design fundamentals | scaling, cache, database, queues, consistency, rate limiting |
| 7 | HLD + LLD | 3 design practices; provider search design; one LLD exercise |
| 8 | DSA intensive | pattern review and timed interview-style problems; explain aloud |
| 9 | Production engineering + AI-DLC | incident story, deployment pipeline, observability, responsible AI workflow |
| 10 | Mock interviews + applications | mocks, targeted applications, feedback loop, final weak-area review |

## Weekly minimums (starting point)

- DSA: 5 sessions × 45–60 minutes
- Core topic: 4 sessions × 45–60 minutes
- Project / system design: 3 sessions × 45 minutes
- Verbal practice: 10–15 minutes most days
- Mock interview: 2 per week from week 6 onward (earlier if useful)
- Applications/networking: 2–4 focused blocks per week once resume is ready

Reduce the counts to fit your real schedule rather than repeatedly missing an unrealistic plan.

## Suggested daily 3-hour template

| Block | Time | Activity |
|---|---:|---|
| DSA | 60 min | Pattern practice, timed solve, verbal explanation |
| Technical depth | 60 min | Java / Spring / React / production topic of the week |
| Project or design | 45 min | Resume interrogation or system design |
| Speaking + log | 15 min | Answer one prompt, record confidence and next step |
