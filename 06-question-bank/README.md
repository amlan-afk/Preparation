## 💡 How Each Question is Structured

Every single question is crafted to meet senior interview bar requirements:
- **Direct Answer:** Crisp, authoritative explanation suitable for an initial 60-second interview response.
- **Under-the-Hood Mechanics:** Explains how the JVM, V8 engine, Spring application context, React Fiber reconciler, or React Native New Architecture (JSI / Fabric) works internally.
- **Production Code Snippet:** Clean, modern code demonstrating real-world idioms (Java 17/21, Spring Boot 3.x, ES2024, React 18/19, Reanimated v3, TurboModules).
- **Pitfalls & Edge Cases:** Common traps interviewers use as follow-ups (e.g., bridge serialization bottlenecks, stale closures, N+1 queries, race conditions, memory leaks).
